# Screenshots and Demo Media

The portfolio README contains no invented or placeholder images. Add approved
captures using this structure:

```text
docs/screenshots/
  web/
    desktop-dashboard.png
    mobile-dashboard.png
    admin-support.png
  android/
    sign-in.png
    budget.png
    reports.png
```

Capture with synthetic staging data only. Remove email addresses, user IDs,
tokens, personal financial records, and browser notifications. Use consistent
viewport sizes, descriptive filenames, and a light/dark theme label. Compress
images without making text unreadable, then update the README gallery.

## Demo video

Record a short walkthrough using the same synthetic staging account. Show sign
in, a transaction, a budget or savings goal, a report, and the support flow.
Do not show credentials or private Firebase Console data. Add the final public
video URL to the README after review; no URL is claimed until one exists.

Suggested outline: 5 seconds of app identity, 20 seconds of sign-in and the
dashboard, 25 seconds covering a transaction and budget, 15 seconds showing a
savings goal and report, and 15 seconds showing support and the admin reply.
Keep the recording under two minutes and avoid Firebase Console pages.
